Для обращений по бассейнам через формы сайта alpool.ru

Оператор и связь

Цель и состав данных

Данные, отправленные через формы сайта, используются для получения и рассмотрения обращения по проектированию, строительству и техническим вопросам бассейнов, связи с заявителем и подготовки ответа.

В зависимости от формы и сведений, которые вы укажете, обрабатываются имя, телефон, email, текст обращения, информация о бассейне или проекте, приложенные файлы и содержащиеся в них сведения. Для обработки заявки также передаются адрес страницы, тип формы, источник обращения и UTM-параметры, если они есть.

Как обрабатываются данные

Данные передаются через API сайта и сохраняются в системе обработки заявок; приложенные файлы сохраняются вместе с заявкой. Для уведомления оператора о поступившей заявке сведения могут передаваться через Telegram. Данные используются для ответа на обращение.

Оператор может получать, записывать, систематизировать, хранить, уточнять и использовать данные для рассмотрения обращения и связи с заявителем. Данные прекращают обрабатываться, когда цель обработки достигнута и отсутствует иное основание для продолжения обработки, предусмотренное законом.

Согласие и обращения

Основание обработки данных, отправленных через форму, — отдельное согласие пользователя. Перед отправкой формы пользователь самостоятельно отмечает пустую по умолчанию галочку. Текст согласия доступен по ссылке в форме и на странице согласия на обработку персональных данных.

Для получения информации об обработке данных, их уточнения или отзыва согласия направьте запрос на aanufriev@list.ru. После отзыва обработка прекращается, если у оператора нет иного законного основания продолжать её.
