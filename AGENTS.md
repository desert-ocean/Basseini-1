# Правила проекта ALPOOL

Для всех публичных страниц сайта, включая новые страницы, SEO-материалы, справочник, калькуляторы, каталог и услуги, не размещайте пользовательские переходы на сторонние коммерческие или информационные ресурсы. Исключение допускается только для проверенной прямой ссылки на нормативный документ на официальном государственном ресурсе; добавьте конкретный адрес в явный список разрешённых адресов проверки.

Внешние материалы можно использовать для исследования. На сайте приводите библиографическое описание: организацию, название, год или редакцию, серию, страницу или таблицу и условия применения. Не выдавайте непроверенные данные за подтверждённые.

Не путайте исходящие пользовательские ссылки с техническими подключениями (API, аналитика, карты, скрипты и шрифты); не меняйте интеграции без анализа. Перед выпуском запускайте `npm run check:external-links`. По существующим страницам вне текущей задачи сначала составляйте инвентаризацию; массовые удаления выполняйте только с разрешения пользователя.

## Единая навигация сайта

- Каждая новая публичная HTML-страница использует общую навигацию ALPOOL: шесть пунктов в порядке «Услуги» (`/#services`), «Почему мы» (`/#why-us`), «Портфолио» (`/#portfolio`), «Статьи» (`/blog/blog.html`), «Справочник» (`/spravochnik/`), «Контакты» (`/#contact`). Для главной страницы допустимы уже используемые локальные якоря `#services`, `#why-us`, `#portfolio` и `#contact`.
- Сохраняйте контактные иконки телефона, WhatsApp (`https://wa.me/79856446654`) и Telegram (`https://t.me/desertocean`). Не добавляйте дополнительные текстовые пункты в основное меню.
- Для разделов используйте корректное активное состояние: услуги, портфолио, статьи или справочник; если раздел определить нельзя, не выделяйте случайный пункт.
- При добавлении страницы запускайте `node scripts/sync-site-navigation.cjs`. При изменении общей навигации проверяйте все публичные HTML-страницы, запускайте `npm run test:e2e` и `npm run check:external-links`.
- Синхронизируемые страницы обновляйте через `node scripts/sync-site-navigation.cjs --write`; скрипт также проверяет уже унифицированные страницы, не перезаписывая их. Технические страницы перенаправления, проверочные HTML-файлы и черновые версии документов не являются страницами сайта и остаются исключениями.
