# Правила проекта ALPOOL

Для всех публичных страниц сайта, включая новые страницы, SEO-материалы, справочник, калькуляторы, каталог и услуги, не размещайте пользовательские переходы на сторонние коммерческие или информационные ресурсы. Исключение допускается только для проверенной прямой ссылки на нормативный документ на официальном государственном ресурсе; добавьте конкретный адрес в явный список разрешённых адресов проверки.

Внешние материалы можно использовать для исследования. На сайте приводите библиографическое описание: организацию, название, год или редакцию, серию, страницу или таблицу и условия применения. Не выдавайте непроверенные данные за подтверждённые.

Не путайте исходящие пользовательские ссылки с техническими подключениями (API, аналитика, карты, скрипты и шрифты); не меняйте интеграции без анализа. Перед выпуском запускайте `npm run check:external-links`. По существующим страницам вне текущей задачи сначала составляйте инвентаризацию; массовые удаления выполняйте только с разрешения пользователя.
