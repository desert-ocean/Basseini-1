## E. Остальные технические замечания

- `elements.html` и `generic.html` не получили `lang="ru"`: их фактическое содержимое на английском, поэтому русская декларация была бы неверной. Оба остаются отдельным решением.
- Description отсутствует у `consent.html`, `privacy.html`, двух шаблонных страниц и нескольких служебных файлов. Ни один description не добавлялся: для legal страниц требуется отдельное решение, для шаблонов — сначала определить судьбу.
- У семи направлений `og:url` всё ещё указывает на прежние root URL с HTTP 404. Не менялось, потому что область исправления ограничена canonical; рекомендуется отдельным изменением синхронизировать `og:url`.
- Других изменений canonical, robots, lang, title, description или sitemap нет. XML остаётся прежним и валидным: семь страниц направлений уже находились в нём по правильным фактическим URL.
